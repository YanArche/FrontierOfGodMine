# Аккаунты WoidWatch на домашнем ПК

Это служба регистрации и входа. Она работает независимо от процесса NeoForge. Постоянный адрес для ключей доступа — https://accounts.noboredgames.win. Браузер привязывает ключ к этому домену. IP игрового сервера задаётся отдельно внутри WoidWatch → Администрирование. Владелец проходит проверку своего GitHub ID через установленный Git Credential Manager; игрокам Git не нужен.

## Установка и постоянная работа

1. На Windows установите 64-битный Python 3.12 или 3.13 для всех пользователей, с доступом из PATH. Распакуйте архив. Откройте PowerShell от администратора в его папке и выполните:
   
   `powershell -NoProfile -ExecutionPolicy Bypass -File .\install-windows.ps1`

2. Для первого запуска выполните `Start-ScheduledTask -TaskName 'WoidWatch Accounts'`. Планировщик запускает службу после каждой загрузки Windows под встроенной учётной записью LocalService, включая загрузку до входа в систему. После сбоя повторяет запуск через минуту. Проверка локально: `Invoke-RestMethod http://127.0.0.1:8787/health` должна вернуть status=ok. Статус задачи: `Get-ScheduledTaskInfo -TaskName 'WoidWatch Accounts'`.

3. В панели Cloudflare откройте используемый Tunnel, список Published application routes и добавьте отдельный маршрут. Hostname — **accounts.noboredgames.win**, Service — **HTTP**, URL — **127.0.0.1:8787**. Коннектор этого маршрута должен работать на том же ПК. Если туннель общий для нескольких коннекторов на разных машинах, создайте выделенный туннель на ПК аккаунтов или обеспечьте доступ до одного origin со всех коннекторов. Существующие записи других поддоменов сохраняются. При локально управляемой конфигурации добавьте правило hostname перед завершающим catch-all и привяжите новый DNS к этому туннелю. Не создавайте второй конфликтующий DNS для этого имени. [Маршруты Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/)

4. Коннектор cloudflared также должен работать после перезагрузки. Для новой установки воспользуйтесь командой установки службы Windows в мастере Cloudflare для вашего туннеля. Токен остаётся на ПК владельца. Для существующей службы проверьте `Get-Service cloudflared | Select Name,Status,StartType` и режим Automatic. Открывать входящий порт 8787 на роутере не требуется. Проверьте с телефона через мобильный интернет `https://accounts.noboredgames.win/health`. После перезагрузки ПК повторите эту проверку до входа в Windows. ПК должен быть включён, подключён к сети и не уходить в сон при питании от розетки.

5. Для одноразового приглашения выполните от администратора `& "$env:ProgramData/WoidWatchAccounts/app/run.ps1" -Invite`. Приглашение действует сутки. Передайте его лично участнику. В лаунчере он нажимает «Мой аккаунт», создаёт passkey, затем вводит код из окна лаунчера в браузере. Сессия для устройства действует до 30 дней. В первой версии один ключ на аккаунт; для сообщества используйте синхронизируемый ключ с доступным владельцу резервным способом восстановления у провайдера.

Для обслуживания остановите задачу через `Stop-ScheduledTask -TaskName 'WoidWatch Accounts'` и сохраните закрытую копию папки data. В ней база SQLite, данные проверки ключей, сессии и ключ cookie. Затем запустите задачу. Повторная установка в ту же папку сохраняет data. Разместите ограничение частоты публичных запросов входа на маршруте Cloudflare. Перед открытием регистрации проверьте восстановление резервной копии на отдельной машине.

## Проверка прямого запуска Java Edition

У владельца проекта должен быть свой публичный Microsoft Application (client) ID: тип desktop/public client с личными Microsoft-аккаунтами, OAuth authorization code + PKCE, loopback redirect http://127.0.0.1/callback с динамическим портом. Для приложений, работающих с Java Game Service, выполните процедуру проверки у Mojang. [Minecraft Help](https://help.minecraft.net/hc/en-us/articles/16254801392141)

После одобрения задайте WOIDWATCH_MICROSOFT_CLIENT_ID в среде тестового процесса лаунчера. Войдите в WoidWatch и нажмите «Играть». Первая привязка открывает системный браузер Microsoft. Клиент получает Xbox/XSTS и Minecraft session, проверяет Java-профиль. Refresh-токен хранится средствами ОС и привязан к локальному профилю сообщества. Проверьте вход в главное меню и на online-mode сервер с настоящей лицензией, отмену и отзыв лицензии/сессии. После проверки внесите публичный client ID в релиз. Начиная с версии 1.2.1, пока собственный ID не настроен, кнопка «Играть» запускает профиль через оригинальный Prism Launcher. Учётной записью Minecraft в этом режиме управляет Prism. Игровые JAR скачиваются из источников Mojang/NeoForge. В каталоге доступна только сборка Frontier of God.
