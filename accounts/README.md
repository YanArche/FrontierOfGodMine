# Аккаунты WoidWatch 1.4

## Проверка на одном компьютере

Распакуйте архив аккаунтов. Установите Python 3.12 или 3.13 с командой python в PATH. Запустите **Test-accounts.cmd**. Первая установка зависимостей требует интернет. Окно выводит одноразовое приглашение. В WoidWatch откройте **Аккаунт**, отметьте **Тестовый сервер на этом ПК**, введите ник, пароль и приглашение и нажмите **Регистрация**. После регистрации сессия уже открыта. Для повторного входа нужны ник и пароль. Закройте окно тестовой службы для остановки. При повторном открытии учётные записи сохраняются и появляется новое приглашение.

Заглушка использует настоящую регистрацию и SQLite; она заменяет только готовность игрового сервера. Слушает 127.0.0.1:18787. База находится в %LOCALAPPDATA%\WoidWatchAccountHost\test\test.sqlite. Используйте отдельный тестовый пароль. Эту службу нельзя публиковать через туннель.

## Серверный комплект

1. Распакуйте **Frontier-Server.zip**. На хосте нужна команда python (3.12/3.13) и доступ в интернет при первом развёртывании. **Prepare-server.cmd** готовит базу, окружение Python, зависимости и файлы модпака. При обновлении существующего хоста сохраните резервную копию миров и базы. Если старая версия запускала отдельную задачу «WoidWatch Accounts», остановите и отключите эту задачу перед переходом: порт 8787 нужен новому комплекту.
2. Запускайте **Start-server.cmd**. После установки NeoForge и принятия владельцем Minecraft EULA один процесс управляет игрой и службой аккаунтов. Пока Minecraft загружает мир, API возвращает 503. После сообщения Done доступны регистрация, вход и проверка сессии. При штатной остановке командой stop служба прекращает принимать входы и завершается вместе с игрой. База сохраняется между запусками.
3. В папке accounts запустите **Create-invite.cmd** и передайте приглашение одному участнику лично. Срок действия — сутки. Регистрация по занятому нику и повторное использование приглашения отклоняются. Пароли длиной 12–128 символов хранятся как scrypt-хеши с индивидуальной солью. Сессия действует 30 дней. Выход в лаунчере отзывает её.
4. Для регистрации с других ПК добавьте в Cloudflare Tunnel отдельный маршрут **accounts.noboredgames.win → http://127.0.0.1:8787**. Коннектор работает на ПК сервера. Игроки открывают «Аккаунт» без флажка тестовой среды. Проверьте HTTPS /health: registration=true только после готовности игры. Добавьте ограничение частоты запросов на стороне Cloudflare.
5. Для автоматического старта после перезагрузки настройте Планировщик Windows на запуск Start-server.cmd под тем же пользователем Windows, которому принадлежит база, с рабочей папкой серверного комплекта. Сначала выполните первый запуск вручную, подтвердите EULA и проверьте штатную остановку. Отключите сон хоста при питании от сети. Для туннеля включите автоматический запуск существующей службы cloudflared.

Новая рабочая база — %LOCALAPPDATA%\WoidWatchAccountHost\production\accounts.sqlite. При наличии прежней базы %ProgramData%\WoidWatchAccounts\data\accounts.sqlite используется её каталог; учётной записи запуска требуются права на запись туда. Делайте резервную копию каталога базы после штатной остановки. База паролей общая для экземпляров, запущенных одним пользователем на одном хосте. В первой версии вход в лаунчер по паролю и существующие браузерные passkey доступны по своим способам входа; имена уникальны в обоих каталогах.

Сессия хранится через DPAPI на Windows и Keychain на macOS. Перед запуском игры лаунчер повторно проверяет её у выбранного сервиса. Это авторизация в лаунчере. Подключение к многопользовательскому Minecraft и контроль входа на игровом сервере — отдельная функция.

### Сетевой вход Minecraft через WoidWatch

Для выделенного сервера обновите папку accounts из WoidWatch-Accounts.zip. Start-server.cmd поднимает службу и Minecraft вместе. Служба сохраняет online-mode=true и проверяет каждого подключающегося по билету WoidWatch. Подпись чата Microsoft отключена через enforce-secure-profile=false. UUID для сетевой игры берётся из аккаунта WoidWatch.

Клиентам нужен WoidWatch 1.9.0 или новее, работающий HTTPS-маршрут службы аккаунтов и адрес игрового сервера. Отдельному серверу друга для использования тех же аккаунтов нужна интеграция с общей службой проверки. Обычный сервер Minecraft с авторизацией Microsoft ожидает сессию Microsoft.
