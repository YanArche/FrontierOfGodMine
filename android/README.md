# WoidWatch Android

Экспериментальный Android-порт. Основа — Amethyst Android, преемник PojavLauncher. Точная ревизия движка закреплена в prepare_engine.py. Исходники и лицензия движка остаются в его рабочей копии. При распространении APK приложите соответствующий исходный код движка с изменениями, лицензии и уведомления.

## Сборка

1. Нужен dist/client.zip, соответствующий pack/index.json. Это клиентский payload.zip из настольного комплекта той же версии.
2. Выполните python android/build_pack.py. Скрипт проверит SHA-256 каждого файла и запишет dist/Frontier-Android.zip.
3. Выполните python android/prepare_engine.py <отдельная-папка-Amethyst> --pack dist/Frontier-Android.zip. Скрипт добавит экран WoidWatch и встроит пакет Frontier в приложение.
4. Из папки Amethyst выполните git submodule update --init --recursive. Собирайте :app_pojavlauncher:assembleDebug с JDK 21, JDK 8 для MioLibPatcher, Android SDK и NDK из требований закреплённой ревизии. Для этого исходного дерева указаны compileSdk 37 и NDK 27.3.13750724 и CMake 3.22.1. Сверьте порядок подготовки ресурсов и JRE с файлом .github/workflows/android.yml в Amethyst.
5. На Android откройте плитку WoidWatch и нажмите «Подготовить сборку». При первом запуске экран подгружает ARM64 Java 21 и открывает встроенный установщик NeoForge 21.1.267. По завершении вернитесь в WoidWatch и запустите выбранный профиль Frontier of God. Для установки Java и компонентов игры нужен интернет.

## Подписанный APK для Redmi Note 13 Pro 4G

После сборки используйте `android/package-apk.ps1` с путём до debug APK и каталога Android Build Tools. Скрипт создаёт или переиспользует отдельный ключ Windows-пользователя, выравнивает, подписывает и проверяет готовый APK. Храните каталог `%LOCALAPPDATA%/WoidWatch Android Signing` и его резервную копию в защищённом месте. Подпись должна совпадать при последующих обновлениях.

## Профиль телефона

Профиль использует 30 FPS, обзор 5 чанков, симуляцию 4, уменьшенную дальность сущностей и включённые субтитры. Экспериментальная комплектация исключает Iris, Distant Horizons, Essential и CustomSkinLoader. Контент сборки, миры, рецепты и квесты используют структуру обычного Frontier. Десктопный профиль и серверный архив не меняются.

На Redmi Note 13 Pro 4G и 5G нужно отдельно проверить рендерер и масштаб разрешения. Начните с 60% и 30 FPS, замерьте время кадра и нагрев после 20 минут в сгенерированном мире и при генерации новых чанков. На устройстве с 8 ГБ RAM начальный ориентир для Java — 3–4 ГБ, с корректировкой по фактическому расходу и выгрузкам приложения Android.

## Что требуется до релиза

- Собрать и установить APK на реальное устройство, проверить импорт, загрузку Java 21 и NeoForge, вход в мир, управление касанием и совместимость модов.
- Провести проверку модов и производительности на конкретном устройстве.
- Подключить рабочий вход WoidWatch, хранение сессии через Android Keystore, игровые билеты, друзей, менеджер, гардероб и обновления. Экран установки пока использует существующий аккаунт и элементы запуска Amethyst.
- Проверить подключение к выделенному серверу после развёртывания службы аккаунтов. Совместные миры через ретранслятор зависят от ещё не готовой общей функции WoidWatch.
