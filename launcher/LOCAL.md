# WoidWatch Launcher 1.3 · локальная игра

На главном экране нажмите **Мой профиль**, укажите игровой ник и при желании заполните «О себе». Профиль сохраняется на этом ПК в папке выбранной сборки, в файле `.frontier/local-player.json`. При переименовании внутренний UUID сохраняется. Для существующей установки лаунчер использует прежний профиль или единственную запись из usercache.json.

Нажмите **Играть**. Нужны установленные Minecraft Java 1.21.1, NeoForge 21.1.267 и игровые ресурсы. Загрузка и проверка сборки отображаются в WoidWatch. Для запуска локального клиента не требуется Prism или вход в Microsoft. Игровой режим — одиночный. Локальный профиль доступен пользователю операционной системы, у которого есть доступ к папке сборки.
