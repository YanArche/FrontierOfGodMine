# Переход на WoidWatch Launcher

Закройте старый лаунчер. В распакованном дистрибутиве клиента замените resources/frontier.jar файлом frontier.jar из этого архива. На macOS выберите «Показать содержимое пакета» и замените Contents/Resources/frontier.jar. Затем откройте прежний EXE или приложение. Полный клиентский архив нового выпуска также подходит для первой установки.

Прежняя папка игры обнаруживается автоматически. Для CurseForge или другой установки нажмите «Импортировать сборку» и выберите папку Фронтира с mods и saves. Лаунчер подключает её на месте, включая миры и клавиши. Закройте игру перед обновлением этой папки.

Лаунчер проверяет подписанный канал GitHub при каждом открытии. Пакет готовится в личной папке пользователя. После закрытия при следующем открытии стартует новая версия. Если новое окно не готово за 45 секунд или процесс завершился с ошибкой, загрузчик возвращает предыдущий рабочий пакет. Версия приложения отображается в заголовке окна, версия сборки — в библиотеке.
