# WoidWatch 1.3 · собственное окно запуска

Эта ветка предназначена для проверки первого входа под собственным публичным Application (client) ID проекта. Стабильная 1.2.1 доступна пользователям до проверки новой версии на реальной лицензии.

В библиотеке кнопки «Войти в Minecraft» и «Играть». Для первого входа клиент запрашивает одноразовый код и показывает его в окне WoidWatch. Игрок подтверждает запрос на официальном сайте Microsoft на компьютере или телефоне. Пароль и MFA обрабатывает Microsoft. После подтверждения окно входа закрывается автоматически. Refresh-токен сохраняется через средства ОС. Сервис аккаунтов сообщества с passkey независим от запуска купленной игры.

«Играть» использует прямой Java-процесс. На странице подготовки показываются проверка сборки, фактическое количество обработанных ресурсов и события NeoForge и Minecraft. Игровое окно и отрисовка мира принадлежат самому Minecraft.

## Проверка перед выпуском

1. Зарегистрировать принадлежащее WoidWatch desktop/public-client приложение для личных Microsoft-аккаунтов, включить public client flows и получить доступ к Minecraft Java Services. Публичный client ID можно передавать без секрета. [Регистрация Microsoft](https://portal.azure.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade) · [Minecraft Help](https://help.minecraft.net/hc/en-us/articles/16254801392141-New-Java-Edition-Game-Service-API-Review-or-Application-Process)
2. Собрать через tools/build-launcher.ps1. Проверять в отдельной копии дистрибутива, запускаемом из среды с WOIDWATCH_MICROSOFT_CLIENT_ID. Для проверки интерфейса напрямую запустить Frontier --library с отдельным путём ready-файла. 
3. Пройти реальный вход, отмену, истечение кода и повторный запуск с действующей лицензией на Windows и macOS. Проверить загрузку ресурсов и вход на online-mode сервер. Только после проверки выпустить подписанное обновление стабильного канала.
